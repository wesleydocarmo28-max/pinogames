# PinoGames — primeira versão

Portal de jogos responsivo, feito em HTML, CSS e JavaScript puro. Não precisa instalar ferramentas para visualizar.

## Como testar no celular ou computador
Abra `index.html` em um navegador. Para publicar no GitHub Pages, envie os arquivos deste pacote para a raiz do repositório `pinogames` e ative Pages nas configurações do repositório.

## Estrutura para adicionar os jogos
- `games/ratos-ninjas/index.html` — coloque aqui o arquivo HTML jogável dos Ratos Ninjas.
- `games/rhythm-slash/index.html` — coloque aqui o arquivo HTML jogável do Rhythm Slash.

Quando esses arquivos existirem, os botões da página inicial abrirão os jogos. Se um jogo usar imagens, sons ou outros arquivos, mantenha-os em pastas próprias dentro da pasta daquele jogo e preserve os caminhos relativos.

## Observação
O portal está pronto como primeira versão visual e funcional (pesquisa, filtros e navegação). Os jogos ainda precisam ser copiados para as pastas indicadas para que os botões abram as versões completas.
